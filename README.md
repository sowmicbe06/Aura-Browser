## Download

Download the latest macOS installer (`.dmg`) from:

**[Download Aura Browser — GitHub Releases](https://github.com/sowmicbe06/Aura-Browser/releases)**

We recommend downloading the installer only from the official repository above.

## Install

1. Open the [Releases page](https://github.com/sowmicbe06/Aura-Browser/releases).
2. Download the latest Aura Browser `.dmg` asset.
3. Open the downloaded disk image.
4. Follow the installation instructions shown in the disk image.
5. Eject the mounted disk image when installation is complete.

If macOS displays a security warning, verify that the installer came from the official release page. Do not bypass macOS security protections unless you have independently verified the application and understand the implications.

Aura Browser is designed around a voice-first browsing experience and productivity-focused workspaces. Refer to the latest release notes for the features available in the current build.
