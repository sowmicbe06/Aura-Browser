# Installing Aura Browser on macOS

## Download

1. Visit https://github.com/sowmicbe06/Aura-Browser/releases.
2. Open the latest release.
3. Download the `.dmg` installer attached to that release.

## Install

1. Open the downloaded `.dmg` file.
2. Follow the installation instructions displayed by the disk image.
3. Launch Aura Browser from the location where it was installed.

The exact installation steps may vary by release.

## Safety

Download the installer only from the official Aura Browser GitHub Releases page. Check the release notes and publisher information. If macOS displays a security warning, do not bypass it unless you have independently verified the application and understand the risk.

For help, visit https://github.com/sowmicbe06/Aura-Browser/discussions.
