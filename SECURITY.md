# Security Policy

The Aura Browser team takes security reports seriously.

## Reporting a vulnerability

Please do not disclose suspected security vulnerabilities in public GitHub Issues or Discussions.

Use GitHub's **Report a vulnerability** feature on the repository if it is enabled. Otherwise, contact the project maintainer through a verified private contact method published in the official repository or project website.

Repository:

https://github.com/sowmicbe06/Aura-Browser

## Include in your report

When possible, provide:

- A clear description of the suspected vulnerability.
- The affected Aura Browser version and macOS version.
- Steps to reproduce the issue.
- Potential impact.
- Proof-of-concept details that do not expose real user data.

Do not include passwords, private keys, access tokens, personal information, or other users' data.

## Coordinated disclosure

Please allow the maintainer reasonable time to investigate and address a report before publicly disclosing technical details. Do not access, modify, or delete data that does not belong to you.

## Supported versions

Please report security concerns affecting the latest version available from the official Releases page. The project will assess older versions as information becomes available.

Thank you for helping keep Aura Browser users safe.
