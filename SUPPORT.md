# Aura Browser Support

Need help with Aura Browser? Start here.

## 1. Download the official installer

Get Aura Browser only from the official GitHub Releases page:

https://github.com/sowmicbe06/Aura-Browser/releases

Check the release notes for version-specific information.

## 2. Ask a question

For installation questions, usage help, and general support, visit:

https://github.com/sowmicbe06/Aura-Browser/discussions

Please include:

- Aura Browser version.
- macOS version.
- What you were trying to do.
- What happened.
- Any relevant error message.

Do not post passwords, private browsing information, API keys, access tokens, or other sensitive data.

## 3. Report a bug

If you can reproduce a problem, search existing reports and then open an issue:

https://github.com/sowmicbe06/Aura-Browser/issues

Include clear reproduction steps and expected versus actual behaviour.

## 4. Security issues

Do not report security vulnerabilities in public discussions or issues. Follow the private-reporting guidance in [SECURITY.md](SECURITY.md).

## 5. Support scope

Community support is provided through the available GitHub project channels. Response times are not guaranteed.
