# Contributing to the Aura Browser Community

Thank you for helping improve Aura Browser.

Aura Browser is currently distributed as **freeware and closed-source software**. This public repository is intended for product downloads, documentation, issue reports, and community discussion. The application source code is not published here.

## Ways to help

You can contribute to the community by:

- Reporting reproducible bugs.
- Suggesting useful features or improvements.
- Sharing clear usability and accessibility feedback.
- Improving documentation through suggestions.
- Helping other users in GitHub Discussions.

## Report a bug

Before opening an issue:

1. Search existing issues to check whether the problem has already been reported.
2. Confirm that you downloaded Aura Browser from the [official Releases page](https://github.com/sowmicbe06/Aura-Browser/releases).
3. Record the Aura Browser version and your macOS version.
4. Write clear steps that reproduce the problem.

Include what you expected to happen, what actually happened, and screenshots or recordings when they are useful. Remove personal information, passwords, tokens, and private browsing data before sharing attachments.

Open a report at [GitHub Issues](https://github.com/sowmicbe06/Aura-Browser/issues).

## Suggest a feature

Use [GitHub Discussions](https://github.com/sowmicbe06/Aura-Browser/discussions) to explain:

- The problem you are trying to solve.
- Your proposed improvement.
- How it would help Aura Browser users.
- Any examples or mockups that clarify the idea.

Please keep suggestions constructive and focused.

## Source-code contributions

The application source code is not available in this public repository. Pull requests that attempt to add, modify, or redistribute proprietary application code are not part of this community contribution process.

If the project maintainer opens a specific documentation or community-maintenance contribution opportunity, follow the instructions in that request.

## Community expectations

Be respectful, constructive, and patient. See [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).

Thank you for supporting Aura Browser.
